# 不背成语 v9 · 部署与终端一键同步指南

## 本次核心升级说明

1. **「日常只学核心词 + 全局搜索全词典」双层平衡架构**
   - **日常背词零负担**：首页核心词书严格聚焦 **701 组公考高频核心词（约 960+ 必考词，含「络绎不绝」「盲从盲信 / 盲信盲从」「浩如烟海」「巧夺天工」「风行草偃」等全部真题与辨析关联词）**，绝不把几万条生僻古词或口语水词塞进你的日常学习任务。
   - **全局查词全覆盖**：顶部搜索框内置 **1,272 组离线常考库**，并打通 **31,648 条《中华新华成语词典》全量词条**（零删减全收录，支持 `盲信盲从 ↔ 盲从盲信` 同素异序匹配与 `lybj` 拼音首字母检索）。搜到的扩展词默认标为「备查词典」，想加入背诵计划只需点右侧 **「＋ 加入背词」**。

2. **对标「不背单词」App 的三键直觉自评 + 艾宾浩斯自动排期**
   - 卡片正面仅保留 **「认识」「模糊」「不认识」** 三个按钮，彻底取消手动判断复习天数的干扰。
   - 选「认识」翻开解析后若发现自己望文生义了，可点左下角 **「记错了 · 改判不认识」** 一键纠偏。
   - 选「模糊」或「不认识」的词会在本组内自动隔牌循环重现，直至真正答出「认识」才算本组过关；同时后台按 **1 → 2 → 4 → 7 → 15 → 30 → 60 天** 艾宾浩斯遗忘临界点与 7 格熟悉度进度条全自动排期。

## Mac 终端极速一键同步到 GitHub（推荐，仅需 5 秒）

解压本压缩包后，直接双击运行里面的 **`一键同步更新到GitHub.command`**（或在终端 `cd` 到解压后的 `gongkao_idiom_pwa` 文件夹执行 `bash 一键同步更新到GitHub.command`）。

脚本会自动完成三件事：
1. 拉取你的仓库 `https://github.com/Hey-sayiwanna/Gongkao-Chengyu`；
2. 自动把 31,648 条全量成语打包成同源 `idiom_full_dict.json` 放进你的仓库（这样 iPhone / iPad 打开时直接从你的 GitHub Pages 同源秒载，不挑网络）；
3. 推送新版 `v9` 代码，等待约 1 分钟刷新即可生效（本地已有背词记录完全保留）。

### 首次在全新 Mac 终端推送提示
- 脚本已内置自动配置仓库级 Git 提交身份（不会再报 `Author identity unknown`）。
- 若这台 Mac 以前从未在终端向 GitHub 推送过代码，首次运行会引导生成一次 GitHub Token 存入 macOS 钥匙串（注意：GitHub 终端不收网页登录密码，只收 `ghp_` 令牌），存好一次后未来所有仓库更新均为双击秒同步。
