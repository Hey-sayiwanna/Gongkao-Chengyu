## 一、使用说明

### 1. 添加到手机主屏幕与电脑桌面

- **iPhone / iPad / Android**：用系统自带 Safari 打开上方网址，点击底部「分享」按钮（向上箭头方框），选择「添加到主屏幕」，桌面即生成无浏览器地址栏的独立全屏应用图标，首次加载后支持断网离线使用。
- **Mac / Windows 电脑**：Mac Safari 点击顶部菜单栏「文件 → 添加到程序坞」，Chrome 或 Edge 点击地址栏右侧安装图标即可独立运行；

### 2. 跨端私钥云同步与本地备份

- **GitHub 私密云同步**：点击右上角「云同步」，填入勾选了 `gist` 权限的个人访问令牌（`ghp_...`），即可通过 [GitHub Gist] 私密仓库在手机、平板与电脑之间一键上传、下载并无损合并背词进度、已剔除熟词、收藏本与每轮背词量设置。
- **多应用共用隔离**：支持与其他刷题工具共用同一枚 Token，成语进度独立存储在专属私密文件中，互不干扰；同时在底部「桌面与同步」页保留本地 `.json` 备份文件的导出与导入。

## 二、主要功能

- **「核心必背 + 全词典秒查」双层词库**：日常学习聚焦精筛后的 **701 组公考 90% 覆盖核心词书**顶部搜索框同时打通 1,272 组离线常考词与3 万余条全量词库，支持拼音首字母、同素异序词检索及一键「加入背词」。
- **三键直觉自评与艾宾浩斯自动排期**：闪卡正面仅保留「认识 / 模糊 / 不认识」三键，无需手动估算复习间隔；
- **全局背词量自定义与熟词极速筛除**：支持在首页「背词设置」中自定义每轮新词数与复习词数并全局生效；遇到早已掌握的简单词可随时一键剔除（移入回收站随时可恢复），把精力集中在高频易错点。
- **全量褒贬标注、三类真题测验与深色模式**：全部四字成语逐条标明褒义、贬义或中性色彩，内置历年国省考[行测言语真题]测验、防望文生义抽测、褒贬色彩秒判特训与错题本；右上角支持一键切换深色模式，兼顾白天与夜间刷词体验。
