# 公考行测｜不背错词

公考行测「不背错词」：678 组高频成语与易错实词、真题练习，支持离线学习和主屏幕安装的 PWA 应用。

## 项目

- `index.html`：主应用
- `manifest.json`：PWA 配置
- `sw.js`：离线缓存
- `icon-192.png`、`icon-512.png`：图标

## 部署

将附件中 `gongkao_idiom_pwa` 文件夹的内容平铺到仓库根目录，并新增 `.nojekyll`；在 GitHub Settings → Pages 设置从 `main` 分支的 `/(root)` 发布。发布后通过 `https://Hey-sayiwanna.github.io/gongkao-chengyu/` 访问（仓库需先重命名为 `gongkao-chengyu`）。

学习进度保存在浏览器本地。
