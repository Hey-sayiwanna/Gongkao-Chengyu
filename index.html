📲 免服务器安装到 iPhone、安卓与 Mac 桌面

依托 GitHub Pages 免费静态托管与标准 PWA 协议，苹果、安卓与电脑均可生成无浏览器地址栏的独立全屏应用图标，支持断网离线刷词：

安卓手机（Edge / Chrome / 自带浏览器）

1. 推荐用安卓版 Edge 或 Chrome 打开网址，点右上角菜单选「安装应用 / 添加到主屏幕」（或点上方绿色一键安装按钮），可生成无浏览器角标的真全屏应用。

2. 用 Vivo、小米、OPPO 等系统自带浏览器打开，点底部菜单「添加至桌面」（若桌面未出现图标，到手机「设置 → 权限管理」开启该浏览器的「桌面快捷方式」权限即可）。

iPhone / iPad（Safari 浏览器）

1. 用系统自带 Safari 打开网址。

2. 点击底部工具栏正中间的「分享」图标（向上箭头方框）。

3. 点「添加到主屏幕」，桌面即生成无地址栏的独立全屏「不背成语」图标。

Mac / Windows 电脑

1. Mac Safari 点顶部菜单「文件 → 添加到程序坞」；Windows / Mac 版 Chrome 或 Edge 点地址栏右侧「安装不背成语」图标。

2. 独立窗口支持键盘空格翻面、数字键 1-4 打分、X 键秒删简单词。

💾 跨设备进度备份 & 扩充词库导入

纯静态网页不经过任何第三方服务器，学习记录与剔除名单保存在当前设备本地。想在 iPhone 与 Mac 之间同步进度，导出 JSON 后通过隔空投送（AirDrop）或 iCloud 云盘发给另一台设备导入即可；也可导入由配套 Python 脚本从开源真题库生成的扩充词包。
